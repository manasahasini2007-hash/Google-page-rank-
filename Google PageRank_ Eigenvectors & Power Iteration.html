Google PageRank using Eigenvalues, Eigenvectors & Power Iteration

Matrix → Transition Matrix → Power Iteration → Stable PageRank → Eigenvector

1. What is PageRank?

PageRank is a number that tells how important a web page is. A page gets a higher PageRank when many pages link to it, especially important pages.

Mathematically, PageRank is the dominant eigenvector of a transition matrix. We find it by multiplying again and again (power iteration).

2. Enter a small web graph

Adjacency matrix: size 2×2, 3×3 or 4×4. Use only 0 or 1. Row i, column j = 1 means "page i links to page j". Separate numbers with spaces, one row per line.

3. Calculate PageRank

Each page splits its "vote" equally among the pages it links to. A page with no outgoing links (dangling page) is treated as linking to every page equally.

Transition matrix M (each column adds up to 1):

PageRank formula:

r = d·M·r + (1−d)/N

r = PageRank vector, M = transition matrix, d = damping factor, N = number of pages.

4. Power Iteration, step by step

Start with , then repeat: r₁ = d·M·r₀ + (1−d)/N, r₂ = d·M·r₁ + (1−d)/N, ...

5. Eigenvalue / Eigenvector

When the values stop changing, applying the formula again gives the same vector back:

G·r ≈ λ·r (G = d·M + (1−d)/N in every cell)

That means r is an eigenvector of G, and λ is its eigenvalue. For PageRank the dominant eigenvalue is about λ = 1.

9. How the project works

  1. We represent web pages using a matrix.
  2. The matrix tells us which page links to which page.
  3. We convert it into a transition matrix.
  4. We repeatedly multiply the PageRank vector by the matrix.
  5. The values gradually stabilize.
  6. The stable vector represents the PageRank.
  7. Mathematically, this is related to the dominant eigenvector.
