📝 About the Project

Google PageRank is a mathematical algorithm used to measure the importance of webpages based on the links between them.

In this project, we create a small network of webpages and use mathematical concepts such as eigenvalues, eigenvectors, and power iteration to calculate the importance of each webpage.

🎯 Why We Chose This Project

We chose Google PageRank because it connects our Mathematics concepts with a real-world application. It helps us understand how eigenvectors and power iteration can be used to rank webpages.

🔢 Mathematical Concepts

1. Eigenvalues

An eigenvalue represents a value associated with a matrix and its corresponding eigenvector.

For PageRank, the important eigenvalue is 1, which represents the stable ranking state.

2. Eigenvectors

The eigenvector gives the PageRank score of each webpage. A higher score means the webpage is considered more important.

3. Power Iteration

Power iteration is a repeated calculation method used to find the dominant eigenvector.

In our project, we repeatedly update the webpage scores until they become stable.

⚙️ How the Project Works

1. Create a network of webpages.
2. Represent the links using a matrix.
3. Assign initial PageRank values.
4. Apply the PageRank calculation repeatedly.
5. Use power iteration to update the values.
6. Continue until the values become stable.
7. Display the final ranking of the webpages.

📊 Example

Suppose there are four webpages:

The algorithm analyzes the links and calculates the importance score of each page.

The final result shows which webpage has the highest PageRank.
